# Chess Quest credits

## Classic pieces

The "Classic" piece set (the twelve pieces drawn in `chess-quest.html` as
`pc-classic-*`) is by **Colin M.L. Burnett** (Wikimedia Commons user
[Cburnett](https://commons.wikimedia.org/wiki/User:Cburnett)), licensed
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

Source files, all on Wikimedia Commons: `Chess_klt45.svg`, `Chess_qlt45.svg`,
`Chess_rlt45.svg`, `Chess_blt45.svg`, `Chess_nlt45.svg`, `Chess_plt45.svg`
and the `d` (dark) versions of the same six. The SVG paths are embedded
unchanged apart from stripping the XML header, whitespace and one stray `id`.

CC BY-SA: keep this credit with the game. Anyone who changes those twelve
drawings has to share the changed drawings under the same licence.

## Everything else

The Friends, Blocks and Shadows piece sets, the owl, every sound effect and
the artwork are drawn or synthesised in the page itself. Spoken names come
from the device's own speech synthesis, when it has one.
