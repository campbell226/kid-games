# Kid Games

Browser games for my two children. One self-contained HTML file per game, no
build step, no dependencies. Open a file in a browser and it runs.

Played at: https://campbell226.github.io/kid-games/

## Layout

    games/<name>/<name>.html    one game, entirely self-contained
    index.html                  the launcher the children open

## Working on it

There is nothing to install and nothing to compile. Edit the HTML file and
reload the browser. See CLAUDE.md for the design rules the games follow.

HOWTO.md is the step-by-step: starting a session, asking for a new game,
and what to check before finishing.
